# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - Unreleased

First release: a port of the Go implementation
([github.com/victorcondackdev/brpay](https://github.com/victorcondackdev/brpay)) to .NET 8.

### Added

- `BrPay.Emv`: EMV MPM TLV parsing, encoding and structural validation with
  positional errors (`EmvParseException.Offset`/`FieldId`), and CRC-16/CCITT-FALSE
  (`Crc16`) with an allocation-free ASCII path.
- `BrPay.Pix`: BR Code decoding (`BrCode.Decode`/`TryDecode`), static and dynamic
  payload generation (`BrCodeBuilder`) with accent transliteration and BCB limits,
  a linter that reports every issue it finds (`Linter.Lint`), Pix key
  validation and normalization (`PixKey`), and EndToEndId parsing and generation
  (`EndToEndId`, backed by `RandomNumberGenerator`).
- `BrPay.Boleto`: barcode and linha digitável parsing for bancário and
  arrecadação (44/47/48 digits), conversions, builders, check digits
  (`CheckDigits`), the February 2025 due-date factor rollover (`DueDateFactor`),
  single-typo recovery (`BoletoCode.SuggestFix`) and hybrid boletos (`HybridBoleto`).
- `BrPay.Documents`: CPF and CNPJ validation, formatting and masking, including
  the alphanumeric CNPJ.
- `BrPay.Decoder`: one entry point that detects and decodes any of the above,
  with lint issues and typo suggestions attached.
- Cross-language parity suite: vectors generated by running the Go
  implementation (`tools/vecgen`) and asserted byte-for-byte, error messages included.
- Property-style robustness tests (20,000 deterministic random and mutated inputs).
- BenchmarkDotNet benchmarks for CRC, TLV parsing, decoding, linting and boleto recovery.
